# 사무실 디자인 고도화 결과

확인일: 2026-09-17. 현재 로컬 사무실의 실제 직원 8명에 적용했다.

## 디자인 방향

짙은 녹색 메뉴, 따뜻한 밝은 배경, 원목 책상과 유리 파티션을 사용한 미니어처 사무실로 정리했다. 회사 현황 → 사무실 → 대표 확인함 순서로 읽고 행동할 수 있도록 구성했다. 캐릭터는 실제 Telegram 프로필과 저장된 꾸미기를 유지한다.

## 변경

- 메뉴·글자·입력란·버튼·업무 카드·직원 상세창의 크기, 여백, 대비와 초점 표시를 통일했다.
- 직원·진행·확인할 업무·누적 완료를 바로 누를 수 있는 요약으로 구성했다. 숫자는 실제 값의 증감 방향으로 짧게 전환하며 움직임 줄이기 설정을 따른다.
- 대표 확인함에 검토 대기 결과를 포함했다. 최근 변경된 업무 3개를 먼저 보여주고 전체 업무 보드로 이동할 수 있다.
- 사무실 소식은 실제 업무 사건을 우선 표시하며 기록 보관함으로 연결한다.
- 연결된 직원 수와 업무 배정 일시정지 상태를 구분해서 보여준다.
- 프로필 44px·직원 이름 13px, 원목 책상·모니터·키보드·컵·창틀·식물·회의실·교육실·휴게실·시상 공간을 적용했다.
- 한 층 25명까지 좌석이 겹치지 않도록 지도의 행 높이를 조절한다. 작은 화면에서는 지도만 가로로 이동하며, 실제 지도 폭이 좁을 때 이동 안내를 보여준다.
- 관람 모드에서 다른 메뉴로 이동하면 관람 모드를 종료한다. 상세창은 키보드 초점을 안에 유지하고 닫은 뒤 원래 위치와 페이지 스크롤을 복원한다.
- 빈 사무실의 시작 안내와 연결 끊김·답변 대기·오래된 진행 표시도 확인했다.

| 기존 확장 업무 흐름 | 협업 계획·실행 등록·교육 적용/철회·자리/공간 편집·답변 대기와 처리 재개 검사 통과 |

독립 검토에서 발견한 관람 모드의 메뉴 복귀 문제와 태블릿 이동 안내 누락을 수정했다. 통합 담당자가 해당 상황을 회귀 검사에 포함해 다시 확인했다. 모바일 빈 사무실의 시작 안내 잘림도 수정하고 검사에 추가했다.

수정 후 독립 검토에서도 390·1440px의 관람 모드→직원·업무·성과 이동 6개 흐름과 768px 지도 안내가 통과했다. 원문 없는 확인 결과는 ignored `output/hermes-office-qa/design-fixes-independent-summary.json`에 있다. 열려 있던 앱 내 사무실 탭을 새로고침해 새 디자인이 표시되는 것도 확인했다.

자동 검사는 수동 접근성 전체를 보장하지 않는다. 100명 화면은 합성 회사이며 실제 100개 모델 동시 실행을 뜻하지 않는다. 이번 작업은 화면과 화면 검사만 변경했고, 실제 업무·원본 봇 설정·실행 권한 변경이나 유료 모델 호출은 하지 않았다.

## 주요 파일과 자료

- `src/components/admin/hermes-office/OfficeApp.tsx`: 화면 구조, 요약, 대표 확인함, 메뉴 이동, 상세창 초점
- `src/components/admin/hermes-office/OfficeMetric.tsx`: 접근성을 유지한 숫자 표시
- `src/components/admin/hermes-office/office-theme.css`: 메뉴·버튼·서식·반응형 디자인
- `src/components/admin/hermes-office/OfficeScene.tsx`, `office-scene.css`: 캐릭터·공간·가구·작업 연출
- `scripts/hermes-office/design-check.mjs`: 실제 회사와 분리된 디자인 회귀 검사
- ignored `output/hermes-office-qa/design/verification.json`: 수치·검사 범위. 같은 폴더의 스크린샷은 합성 명부이며, 실제 명부 화면은 `output/hermes-office-qa/office-1440.png`, `office-390.png`에 있다.

화면 검토에 [Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md)의 초점·대비·반응형·모션 기준도 참고했다.
