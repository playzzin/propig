# 국내 증시 웹·Windows 위젯

## 사용 경로

- 웹의 /propig 대시보드에서 **국내 증시**를 누른다. 직접 경로는 /propig/market이다.
- Windows 앱의 **위젯 → 국내 증시**에서 차트를 연다. 로그인 전에는 **국내 증시 위젯 열기** 버튼을 쓴다. 기존 위젯과 같은 창 위치·크기·항상 위 설정이 적용된다.
- 공공데이터포털에서 지수시세정보와 주식시세정보 이용을 신청하고 본인의 서비스 키를 화면에 입력한다. 웹과 Windows 위젯은 각 화면이 열려 있는 동안 개인 인증키를 보관한다. **인증키 지우기**로 조회와 현재 화면의 키를 지울 수 있다. [지수시세정보](https://www.data.go.kr/data/15094807/openapi.do) · [주식시세정보](https://www.data.go.kr/data/15094808/openapi.do)
- 코스피·코스닥 버튼으로 지수 차트를 바꾸거나 종목명·6자리 코드로 국내 상장 주식을 찾는다. 1개월·3개월·6개월·1년, 종가선·캔들을 전환할 수 있다. 종가는 원 단위 주가와 포인트 단위 지수를 구분한다.

## 데이터와 연결

- 두 화면은 MarketDashboard를 공유한다. 웹 워커에서 금융위원회 REST V2 지수와 주식 API에 직접 요청한다. 데이터 기준 거래일을 표시한다. 시세는 기준일 다음 영업일 오후 1시 이후 갱신된다. [금융위원회 금융공공데이터 FAQ](https://www.fsc.go.kr/in060501)
- 서비스 키는 포털 API의 HTTPS 요청에 포함되고 브라우저 저장소나 앱 설정을 사용하지 않는다. 화면에 데이터 출처와 포털 이용 조건을 확인할 수 있는 링크를 표시한다. 금융위원회 공지상 현재 공공누리 4유형은 2026년 12월 17일부터 기존 API에도 1유형으로 일괄 변경될 예정이다. [금융위원회 이용 조건 변경 공지](https://www.data.go.kr/bbs/ntc/selectNotice.do?originId=NOTICE_0000000005172)
- Windows는 지정된 ProPig의 /propig/desktop/market을 분리된 InPrivate WebView2에 연다. 공공데이터포털 이용 안내 링크는 기본 브라우저로 연다. 실제 운영 앱에서 사용하려면 해당 웹 경로와 새 Windows 패키지가 모두 반영되어야 한다.
- TradingView 무료 임베드에서는 KRX의 삼성전자와 에코프로비엠이 TradingView 사이트 전용 심볼로 표시됐다. 공식 발급 키로 개인 열람이 가능한 금융위원회 API를 사용했다. [TradingView 위젯 지원 안내](https://www.tradingview.com/widget-docs/faq/)

## 검증과 남은 확인

- 공식 V2 엔드포인트에서 ProPig 웹 출처에 대한 CORS 응답과 키 미제공 시 401을 확인했다. 발급 키를 사용한 실제 시세 요청은 사용자 이용 신청·승인 후 화면에서 확인한다.
- 9950X의 Chromium에서 공공데이터포털 응답 형식의 테스트 데이터로 지수 선택, 종목명·코드 검색, 거래일 선택, 선·캔들, 페이지 구분과 인증 오류를 확인했다. Windows 빌드를 통과하고, 격리된 WPF 검수 창의 WebView2에서 공용 인증키 입력 화면을 확인했다.
- GitHub Actions에서 정적 웹과 Windows MSIX를 검증한다. 운영 데이터는 사용자 본인 키로 공식 API에서 받아 표시한다.
