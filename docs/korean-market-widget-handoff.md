# 국내 증시 웹·Windows 위젯

## 사용 경로

- 그뚠웹의 **상점 → 국내 증시 → 등록**을 누르면 같은 ProPig 계정의 대시보드에 주식 위젯이 추가된다. 대시보드에서 위치와 숨김 상태를 조절할 수 있다. **PC 위젯 → 국내 증시**나 `/propig/market`에서도 종목을 조회할 수 있다.
- Windows의 그뚠뎃에서는 **위젯 → 국내 증시**에서 차트를 연다. 로그인 전에는 **국내 증시 위젯 열기** 버튼을 쓴다. 기존 위젯과 같은 창 위치·크기·항상 위 설정이 적용된다.
- 공공데이터포털에서 지수시세정보와 주식시세정보 이용을 신청한다. 두 항목의 승인이 끝나면 본인의 서비스 키를 **공공데이터포털 인증키**에 입력하고 **연결**을 누른다. [지수시세정보](https://www.data.go.kr/data/15094807/openapi.do) · [주식시세정보](https://www.data.go.kr/data/15094808/openapi.do)
- 코스피·코스닥 버튼으로 지수 차트를 바꾸거나 종목명·6자리 코드로 국내 상장 주식을 찾는다. 1개월·3개월·6개월·1년, 종가선·캔들을 전환할 수 있다. 종가는 원 단위 주가와 포인트 단위 지수를 구분한다.

## 다음에 열 때 자동 연결하기

- **이 기기에서 연결 기억**을 선택하면 현재 기기의 브라우저·앱 프로필에 인증키를 암호화해 저장한다. 같은 프로필과 계정으로 위젯을 다시 열면 저장한 키로 시세를 다시 조회한다. 다른 기기나 브라우저 프로필, Windows 바탕화면 위젯을 처음 사용할 때는 각각 한 번 입력한다.
- 로그인한 계정마다 저장 공간이 구분된다. 로그아웃 상태에서 입력한 키는 해당 프로필의 게스트 연결에 속한다. 공용 컴퓨터를 여러 사람이 같은 브라우저 프로필에서 게스트로 사용한다면 **이 기기에서 연결 기억**의 선택을 해제한다.
- **인증키 변경**으로 다른 키를 입력하고 **인증키 지우기**로 이 프로필에서 현재 계정 또는 게스트의 연결을 삭제한다. 저장을 선택하지 않은 키는 창을 닫으면 다시 입력해야 한다. 저장에 실패한 새 키도 현재 창에서만 쓸 수 있다. 이전 키의 삭제에 실패했다는 안내가 뜨면 저장소 접근을 복구한 뒤 **저장된 인증키 지우기**로 재시도한다. 브라우저의 사이트 데이터를 삭제하면 기억해 둔 키도 지워진다.
- 이전 버전에서 창에 입력했던 키는 창을 닫으면 사라진다. 예전 Windows 앱의 국내 증시 창은 InPrivate 모드로 열린다. 창을 닫아도 연결을 기억하려면 전용 저장 프로필을 사용하는 그뚠뎃 패키지로 업데이트하고 처음 한 번 키를 입력한다.

## 데이터와 연결

- 두 화면은 MarketDashboard를 공유한다. 웹 워커에서 금융위원회 REST V2 지수와 주식 API에 직접 요청한다. 데이터 기준 거래일을 표시한다. 시세는 기준일 다음 영업일 오후 1시 이후 갱신된다. [금융위원회 금융공공데이터 FAQ](https://www.fsc.go.kr/in060501)
- 서비스 키는 공식 시세 API에 보내는 HTTPS 요청에 사용한다. 연결을 기억하면 Web Crypto로 생성한 내보내기 불가 AES-GCM 키와 인증키 암호문을 해당 출처의 IndexedDB에 저장한다. 화면에는 데이터 출처와 포털 이용 조건을 확인할 수 있는 링크가 있다. 금융위원회 공지상 현재 공공누리 4유형은 2026년 12월 17일부터 기존 API에도 1유형으로 일괄 변경될 예정이다. [금융위원회 이용 조건 변경 공지](https://www.data.go.kr/bbs/ntc/selectNotice.do?originId=NOTICE_0000000005172)
- 새 Windows 패키지는 `/propig/desktop/market`을 그뚠뎃 메인 창과 분리된 국내 증시 전용 WebView2 프로필에서 연다. Windows 앱에서 로그인한 계정마다 프로필이 다르며 로그아웃한 상태에서는 게스트 프로필을 쓴다. JavaScript의 네이티브 메시지 브리지와 호스트 객체 접근은 비활성화되어 있다. 공공데이터포털 이용 안내 링크는 기본 브라우저에서 연다. 운영에서 창을 닫았다가 다시 연결하려면 웹 변경과 Windows 패키지 업데이트가 모두 필요하다.
- TradingView 무료 임베드에서는 KRX의 삼성전자와 에코프로비엠이 TradingView 사이트 전용 심볼로 표시됐다. 공식 발급 키로 개인 열람이 가능한 금융위원회 API를 사용했다. [TradingView 위젯 지원 안내](https://www.tradingview.com/widget-docs/faq/)

## 검증과 남은 확인

- 공식 V2 엔드포인트에서 ProPig 웹 출처에 대한 CORS 응답과 키 미제공 시 401을 확인했다. 발급 키를 사용한 실제 시세 요청은 사용자 이용 신청·승인 후 화면에서 확인한다.
- 9950X의 Chromium에서 공공데이터포털 응답 형식의 테스트 데이터로 지수 선택, 종목명·코드 검색, 거래일 선택, 선·캔들, 페이지 구분과 인증 오류를 확인했다. Windows 빌드를 통과하고, 격리된 WPF 검수 창의 WebView2에서 공용 인증키 입력 화면을 확인했다.
- `node scripts/verify-pc-widgets.cjs`는 실제 대시보드 컴포넌트에 모의 저장소와 시세 응답을 연결한다. 최초 연결, 창을 닫았다가 재연결, 계정·게스트 전환, 키 변경·삭제, 저장 거부, 구형·신형 Windows 프로필을 검사한다.
- GitHub Actions에서 정적 웹과 Windows MSIX를 검증한다. 운영 재연결 확인은 배포된 웹과 업데이트한 Windows 앱에서 각각 진행한다. 승인된 키로 연결을 기억한 뒤 창을 닫았다가 열어 삼성전자(`005930`)를 검색하고, 양쪽의 기준 거래일과 종가, 차트를 대조한다.
