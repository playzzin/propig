# Hermes AI Office 사용 안내

## 지금 열기

[사무실 열기](http://127.0.0.1:3010)

다음에 켤 때는 `scripts/hermes-office/start-office.cmd`를 실행합니다. 지금은 PC 안에서 사용하며, VPS는 나중에 연결합니다.

## 현재 적용 상태

- 기존 Telegram 봇 8명의 실제 이름·프로필 사진·스킬·설치 라이브러리·지침을 조회합니다.
- 8개 봇에 공식 업무 이벤트 연결을 설치했습니다. 기존 기록 관찰기는 연결 복구를 돕습니다.
- 아래 회사 관리·협업·교육·공간 기능은 구현되어 있습니다.
- **실제 AI 실행 확인을 완료했습니다.** 사용자가 승인한 기본 봇 1회 실행에서 “연결 확인 완료” 응답을 받았고, 작업 중 캐릭터 표시부터 검토·완료 기록까지 확인했습니다.
- 후속 순차 검사에서는 AI 분담안·GPT/Grok 협업·회의·교육 실습 총 7건을 각각 한 번 실행하고 결과를 확인했습니다. [순차 검증 결과](hermes-office-phase3-results.md)에서 완료 항목과 남은 확인을 볼 수 있습니다.
- 직접 보낸 Telegram 요청도 시작부터 최종 응답까지 확인했습니다. 실제 답변 124자가 사무실에 동일하게 저장됐으며, 업무 보드에서 검토할 수 있습니다.
- 확인 업무 이후 추가 실행은 일시정지했습니다. 사무실을 다시 켜면 **연결 상태 확인만 자동 시작**하며, AI 업무 실행은 별도 실행 모드를 켜야 합니다.
- 100명 검사는 별도 테스트 회사에서 수행했습니다. 실제 100개 봇을 확보하거나 100개 모델을 동시에 호출한 검사가 아닙니다.

## 처음 사용할 순서

### 새 사무실 화면

- 위쪽 **함께하는 직원·진행 업무·누적 완료**를 누르면 관련 화면으로 바로 이동합니다.
- **확인할 업무**를 누르면 대표 확인함으로 이동합니다. 검토 대기 결과·승인·추가 답변·도움 요청을 최근 순으로 보여줍니다.
- 지도에서 직원을 누르면 상세 정보가 열립니다. 모바일·작은 창에서는 지도 안을 좌우로 움직이면 다른 직원의 자리를 볼 수 있습니다.
- **관람 모드**는 사무실을 넓게 보여줍니다. 종료 버튼을 누르거나 다른 화면으로 이동하면 메뉴가 다시 나타납니다.
- **실행 연결**은 연결 준비 상태입니다. **사무실 업무 배정 일시정지**는 Office가 새 업무를 배정하지 않는 상태이며, Telegram에서 직접 내린 명령의 기록은 계속 반영됩니다.

### 게임형 사무실 사용하기

- 원목 책상, 창문, 화분과 입구, 회의실·교육실·휴게실·명예의 전당을 게임처럼 입체적으로 보여줍니다. 직원의 얼굴은 연결된 Telegram 프로필을 사용합니다.
- 지도 위 **− / +**로 확대·축소합니다. **전체 보기**는 현재 층을 한눈에 보여주며, 가운데 **퍼센트 버튼**은 기본 크기로 돌아갑니다. 작은 화면의 전체 보기에서는 이름이 작아지므로 확대해서 직원을 선택하세요.
- **업무석 / 공용 공간**으로 지도 안의 해당 구역을 찾아갑니다. 지도가 화면보다 크면 지도 안에서 좌우·위아래로 움직일 수 있습니다. 키보드로 지도를 선택한 뒤 방향키도 사용할 수 있습니다.
- **애니메이션 끄기 / 켜기**로 움직임을 조절합니다. 선택은 이 브라우저에 저장됩니다. 기기의 ‘동작 줄이기’ 설정을 켜면 움직임을 멈춥니다. 배치 편집 중이거나 화면이 숨겨져 있을 때도 사무실 동작을 잠시 멈춥니다.
- 최근 실제 작업이 확인된 직원만 타이핑합니다. 답변 대기는 말풍선, 최근 결과 도착은 체크 표시로 구분합니다. 회의·교육 업무가 확인되면 공간이 있는 방으로 이동하며 원래 책상은 남아 있습니다.
- 포상 축하와 교육 안내, 호흡·걷기 동작은 기록에 연결한 시각적 연출입니다. 연결 끊김이나 진행 확인이 오래된 직원을 작업 중으로 꾸미지 않습니다.
- **사무실 배치 편집**으로 저장한 방 위치·크기와 직원 좌석은 새 디자인에서도 사용합니다. 방이 작아 직원이 들어갈 자리가 부족하면 해당 직원은 업무석에서 상태를 표시합니다.

### 회사 운영 순서

1. **직원·조직 → 부서 만들기**에서 조직을 정합니다.
2. 직원을 눌러 부서·직책·상사·캐릭터·소품·좌석을 저장합니다. 사람에게 보이는 좌석 번호는 1~100입니다.
3. Telegram에서 평소처럼 해당 봇에 지시합니다. 사무실은 새로 저장되는 업무부터 반영합니다.
4. **업무 보드**에서 요청, 진행 내용, 결과, 다음 행동을 확인합니다.
5. 결과를 완료 조건과 비교해 **품질 점수·검토 의견**을 남깁니다.
6. 통과한 결과는 **승인 대기 → 완료**, 보완할 결과는 **수정 요청 → 재작업**으로 처리합니다.
7. 완료된 업무의 근거로 포상이나 개선 면담을 기록합니다.

## 업무 실행과 중지

**회사 설정**에서 실행 일시정지, 동시 실행 수, 일일 실행 횟수, 업무당 제한 시간을 정합니다.

- 일일 횟수는 한국시간 오전 9시에 새 날짜로 계산합니다.
- 이 한도는 Office가 배정하는 업무에 적용됩니다. Telegram에서 직접 지시한 업무까지 통제하지 않습니다.
- 실행 연결부를 별도로 활성화해야 화면의 예약 업무가 실제 모델에 전달됩니다.
- 현재 자동 시작은 연결 확인 모드입니다. 이 모드는 회사 설정에서 일시정지를 해제해도 모델 업무를 호출하지 않습니다. 추가 실제 업무를 실행할 때는 허용할 업무·한도를 정하고 업무 실행 모드를 켭니다.
- 직원별 전용 API와 프로필을 확인한 뒤 배정하며, 한 직원은 Office 업무를 동시에 하나만 맡습니다.
- 중지를 누르면 **중지 요청**으로 표시하고, Hermes에서 실제 종료를 확인한 뒤 **취소**로 바뀝니다.
- 제한 시간이 지나면 중지를 요청합니다. 즉시 종료를 보장하는 강제 전원 차단 방식이 아닙니다.
- 실행 접수 여부가 불명확하면 자동 재시도하지 않습니다. 중복 요금이 발생하지 않도록 Hermes 상태를 먼저 확인합니다.

## 협업과 회의

### 빠른 분담

**프로젝트 → 협업 계획 만들기**에서 목표와 참여 직원을 선택합니다. 조사·제작·개발 템플릿으로 분담 초안을 만든 뒤 담당자, 요청, 완료 조건, 선행 단계를 수정합니다. 이 템플릿 초안은 정해진 규칙으로 작성됩니다.

### AI에게 분담안 맡기기

**AI에게 분담안 요청**에서 계획을 작성할 직원과 참여 직원을 선택합니다. 실제 작성 업무가 대기열에 들어갑니다. 결과가 도착하면 **분담안 가져오기**를 누릅니다.

결과 형식·담당자·선행 관계가 맞는지 확인한 후 초안으로 가져오며, 잘못된 결과는 오류를 설명하고 반영하지 않습니다. 가져온 초안도 직접 확인하고 **실행 등록**해야 직원들의 업무가 생성됩니다.

### 결과 인계

실행 등록된 협업은 선행 직원의 실제 결과가 도착하면 다음 직원에게 결과를 전달합니다. 업무를 자동으로 최종 승인하지는 않습니다.

앞 직원이 결과를 수정하면 이미 전달한 버전과 수정 여부가 남습니다. 영향을 받은 결과는 최신 근거로 재작업해야 승인할 수 있습니다. 당시 사용한 결과물과 이전 시도도 보존됩니다.

### 회의

회의는 참석자별 의견 작성과 의장의 결론 정리로 구성합니다. 기본 회의는 최대 10명의 발언과 의장 요약 1회, AI가 작성하는 계획은 총 10단계까지입니다. 의장은 실제 의견을 받은 뒤 결정·미결 사항·후속 담당을 정리합니다. 끝없이 서로 호출하는 회의는 만들지 않습니다.

## 교육과 개선

1. **교육·지식**에서 교육 내용을 초안으로 작성합니다.
2. 실제 결과나 확인 근거를 적고 **검증 완료**로 바꿉니다.
3. 적용할 직원과 교육을 선택해 **교육 적용**을 누릅니다.
4. 필요하면 **실습 업무 배정**으로 실제 연습을 맡깁니다.
5. 효과가 없거나 잘못 적용했다면 해당 교육 버전의 **적용 철회**를 누릅니다.

적용할 때의 내용과 근거를 복사해 보관하므로, 나중에 교육 원문을 수정해도 이미 적용한 내용이 몰래 바뀌지 않습니다. 철회한 교육은 다음 Office 업무에 전달하지 않습니다.

교육은 Office 업무에 전달하는 참고 지침입니다. 모델을 재훈련하거나 원래 Hermes 파일·도구 권한을 바꾸는 기능은 아닙니다.

## 성과·포상·재미 요소

- 직원별 완료량·진행량·품질 점수·기한 준수·재작업·수집된 비용을 확인합니다.
- 비용을 수집하지 못한 작업은 **미수집**으로 표시합니다.
- 포상에는 완료 업무와 근거가 필요합니다. 개선 면담은 문제와 다음 행동을 기록합니다.
- 실적에 따른 포상·교육 제안은 근거와 함께 표시합니다. 최종 인사 판단은 사용자가 합니다.
- 캐릭터는 Telegram 프로필 얼굴을 사용하고 몸체·색·안경·헤드셋·넥타이를 꾸밀 수 있습니다.
- 실제 업무 상태에 맞춰 타이핑하거나 회의·교육 공간으로 이동합니다.
- 교육 적용 안내와 포상 축하 장면은 기록에 연결된 짧은 연출입니다.

연출은 실제 PC 화면 녹화가 아닙니다. 봇이 열어 둔 브라우저나 터미널의 영상 전송은 연결하지 않았습니다.

## 새 직원과 공간 확장

새 Telegram 봇을 Hermes 프로필에 정상 연결하면 기본 10분 간격으로 자동 확인합니다. **봇 정보 확인**으로 바로 갱신할 수도 있습니다. 주기와 자동 확인 여부는 회사 설정에서 변경합니다.

새 프로필의 실행 연결도 이미 준비되어 있으면 연결 확인기에 자동 추가합니다. 기존 직원을 다시 시작할 필요가 없으며 새 직원의 유료 업무 실행은 자동으로 켜지지 않습니다. 한 직원의 연결 문제는 해당 직원에게 표시하고 다른 직원의 연결은 유지합니다. 아직 실행 연결이 없는 새 봇은 그 프로필만 대상으로 설정을 준비합니다.

실제로 확인한 고유 봇만 등록하며 같은 봇은 직원 한 명으로 유지합니다. 기존 부서·직책·좌석·꾸미기는 보존합니다. 새 직원에게 빈자리를 배정하고, 25석마다 층과 기본 공용 공간을 추가합니다. 최대 100명·4층을 지원합니다.

**사무실 배치 편집**에서 회의실·교육실·휴게실·시상 공간의 위치와 크기를 정하고, 직원 자리를 이동하거나 맞바꿉니다. 층의 직원 수에 따라 화면 공간도 조절됩니다.

봇 계정 자체를 대신 생성하는 기능은 아닙니다. 새 봇의 계정과 Hermes 연결이 먼저 필요합니다.

## 상태를 읽는 법

| 표시 | 뜻 |
|---|---|
| 회사 기록 연결됨 | 화면과 회사 기록 저장소 연결 |
| 기록 관찰 연결 | 새 Telegram 기록을 읽는 연결 |
| 실행 준비됨 | 해당 직원의 실제 API·프로필·조회·중지 기능 확인 |
| 작업 중 | 최근 실제 작업 이벤트 또는 실행 상태 확인 |
| 답변 대기 | Telegram 봇이 추가 질문을 보낸 상태. 해당 대화에서 답하면 이어서 진행 |
| 실행 확인 중 | 작업은 열려 있지만 최근 진행 확인이 부족함 |
| 검토 대기 | 결과가 도착했으며 확인이 필요함 |
| 실행 예약 | 대기열에 저장됨, 아직 모델 실행 전 |
| 연결 끊김 | 최근 응답 없음. 업무 성공·실패를 추정하지 않음 |

현재 8개 봇의 연결과 새 Telegram 요청의 시작·중간 진행·최종 응답을 확인했습니다. 추가 질문을 기다리는 업무는 **답변 대기**로 표시하고 **대표 확인함**에도 표시합니다. 확인한 요청은 답변이 도착해 **검토 대기**로 바뀌었으며, 원본과 사무실 결과 124자가 일치합니다. 공식 연결은 응답 앞부분 최대 500자를 전달하므로 긴 답변의 전체 원문은 Telegram에서 확인합니다.

## 기록과 복구

**회사 기록 내보내기**는 직원·업무·이전 결과·검토·비용·협업·교육·회사 기록을 Markdown 보고서로 저장합니다. 기록 보관함에서는 오래된 사건도 더 불러올 수 있습니다.

데이터는 PC의 `output/hermes-office/`에 저장됩니다. `restart-office.ps1`는 회사 DB의 복구 사본을 만든 뒤 사무실 프로그램과 연결 상태 확인기를 다시 시작합니다. 백업은 하위 `backups/`에 있습니다. 원본 봇 서비스는 다시 시작하지 않습니다.

Windows에 로그인하면 사무실과 연결 확인기가 자동으로 켜지도록 등록했습니다. 사무실 서버가 종료되거나 응답하지 않으면 복구를 시도합니다. 자동 시작 프로그램은 AI 업무를 추가로 실행하지 않습니다. 실제 서버 종료 후 복구는 확인했으며, PC 재부팅 검사는 아직 하지 않았습니다.

## 순차 구현 후 확인한 내용

- 실제 AI 분담안 1건, 서로 다른 GPT·Grok 직원의 결과 인계 2건, 두 의견과 의장 요약으로 구성한 회의 3건을 확인했습니다.
- 교육에 적은 보고 형식이 실제 응답에 반영되는 실습 1건을 확인했습니다. 시험용 교육은 철회하고 기록은 남겼습니다.
- 위 7건은 각각 한 번만 실행했습니다. 완료 점수는 짧은 연결 검사 기준이며 일반 업무능력 평가가 아닙니다.
- 별도 시험 사무실에서 8→25→50→100명으로 늘리고 약 3분간 2,004개 합성 이벤트를 처리했습니다. 중간 종료·재시작 뒤 직원·좌석·결과가 보존됐습니다.
- 후속 시험에서는 10분간 6,204개 이벤트와 100개 결과를 확인했습니다. 별도 연결 확인기도 같은 프로세스에서 8명→100명으로 늘리고, 한 직원 오류·잘못된 설정에서 다른 연결이 유지되는 것을 확인했습니다. 실제 AI 100개 동시 실행 시험은 아닙니다.

인증 키와 원본 환경 파일은 공유하지 마세요. 실행 중인 SQLite 파일 하나만 복사하지 말고 제공한 백업 기능을 사용합니다.

실제 직원 8명과 업무 12건의 백업을 별도 사무실로 복원해 결과와 기록이 일치하는지 확인했습니다. 복원 사본은 새 폴더에 만들며 실행을 일시정지하고 연결 키를 복사하지 않습니다. [직원 확장·복원 검증 결과](hermes-office-phase4-results.md)에 자세한 범위가 있습니다.

## 남아 있는 실제 환경 확인

- 100개 실제 봇 계정 확보와 PC에서의 장시간 운영 확인. 100명 화면·기록 시험은 실제 AI 100개 동시 실행 시험과 구분합니다.
- 실제 PC 재부팅·재로그인 후 자동 시작 확인. 프로그램 직접 실행과 서버 종료 후 복구는 확인했습니다.
- VPS 연결과 외부 접속 환경: 사용자가 나중으로 지정한 단계
