# 대표통계 모션그래픽 구현 인계

## 결과

`/corp/company/ceo-intro`의 대표통계 탭을 기술력·체중·누적 작업시간·잔고의 통합 모션그래픽으로 교체했다. 상승·하강 곡선, 기술력 레이더, 100~150kg 게이지, 누적 작업시간 막대, 음수 잔고 워터폴을 함께 보여준다.

- 다섯 단계는 누적 작업시간 12/16/20/40/48h, 기술력 10/30/55/80/99, 체중 100/112/125/138/150kg, 잔고 1,000/760/480/170/−100만원이다. 단계 비교표의 시간을 누르면 해당 상태로 이동한다.
- 최초 진입 시 20초 모션을 한 번 재생한다. 각 단계 사이를 부드럽게 보간하며 숫자·진행점·그래프·비용표·설명 수치를 같은 위치에 맞춘다. 정지·재개·처음부터 보기·지표 직접 선택을 지원한다.
- 잔고는 항상 시작 1,000만원에서 현재 보간된 네 비용을 뺀 값이다. 최종 비용은 식대 1,000만원, AI 토큰 50만원, 구독 30만원, 장비 20만원으로 총 1,100만원이다. 식대 비중은 약 91%이고 잔고는 −100만원이다. 비용 요약은 네 열·한 값 행으로 압축했다.
- 통합 곡선은 지표마다 범위가 다름을 표시한다. 잔고 0선과 적자 영역을 구분하며 음수 막대 높이는 양수로 계산한다. 시간은 하루 배분이 아니라 여러 구간의 누적 작업시간이다.
- 화면 밖과 숨김 문서에서는 모션 시간을 정지한다. `prefers-reduced-motion`에서는 최종 상태를 정적으로 보여주며 단계 직접 선택도 가능하다. 화면 읽기 안내는 매 프레임이 아닌 단계 변경 시에만 갱신한다.
- 데스크톱 4열, 중간 크기 2열, 모바일 1열 상세 차트를 제공한다. 대표인사말·대표이력서·창업배경·회사통계는 기존 흐름을 유지한다.

## 파일

- `src/components/corp/ceoStatisticsData.ts`: 다섯 작업 단계와 네 지표의 단일 데이터 원본.
- `src/components/corp/CeoStatisticsCharts.tsx`: 시간 제어를 부모에 맡기는 SVG 그래프.
- `src/components/corp/CeoStatisticsExperience.tsx`: 화면 구성, 선택, 재생과 모션 수명 관리.
- `src/components/dashboard/Dashboard2Experience.tsx`: 대표통계 지연 로딩 및 전용 패널 연결.
- `scripts/verify-ceo-statistics-browser.mjs`: 독립 기대값과 브라우저 검증. 기본 주소는 `http://localhost:3002`, `BASE_URL`로 변경 가능.

## 실제 검증

2026-10-28 기준 다음 검사를 통과했다.

- 변경한 제품 파일 ESLint, 전체 `npm run type-check`, Linux 격리 환경의 전체 `npm run build`.
- 빌드 스냅샷과 최종 제품 소스 4개 파일의 SHA-256 일치.
- 개발 서버와 최종 정적 빌드 모두 1440px·390px 대표통계 브라우저 검사 통과. 다섯 단계의 15개 비교 셀, 누적시간 5개 막대, 약 2초 시점의 중간값, 비용 합계, 음수 잔고 곡선·막대, 단계 선택, 재생·정지·재개, 키보드, 동작 줄이기, 탭 전환을 확인했다.
- 최종 정적 빌드에서는 재생 중 설명·태그가 현재 보간 값과 일치하는 회귀 검사도 통과했다. 수동 확인 예: 기술력 20, 체중 106kg, 누적 14h, 지출 122만원, 잔고 878만원.
- 20초 이야기의 1회 완료는 데스크톱에서 검사했다. 문서 숨김은 합성 visibility 이벤트로, 화면 이탈은 실제 IntersectionObserver로 검사했다.
- 새 통계 영역 axe WCAG A/AA 위반 0건, 런타임·hydration 오류 0건. 가로 넘침·그래프 글자 잘림·이미지 누락 없음. PC·모바일 실제 캡처도 확인했다.
- 최종 정적 빌드의 `verify-corp-pages.mjs`: 기업 페이지 5개 × 데스크톱·모바일 모두 통과.

최신 검증 증거는 ignored 경로 `output/ceo-statistics-expenses-20261028/`에 있다. 최종 기준은 `final-checks.json`, `static-browser-results.json`, `static-browser/results.json`이다. 초기 진단 실패 파일은 최종 결과가 아니다.

## 범위와 한계

모든 통계는 재미를 위한 창작 시나리오다. 실제 기술 평가·몸무게·자산 데이터와 연결하지 않았으며 화면에도 명시했다. 체중 단위는 kg, 예산·비용 단위는 만원이다. 브라우저 검증 범위는 Chromium이며 실제 모바일 기기와 다른 브라우저 엔진은 별도로 검사하지 않았다. 구현 단계에서는 로컬 검증만 진행했고, 2026-10-29 사용자 요청으로 제품 쇼릴과 함께 커밋·푸시·Hosting 릴리스 절차를 진행한다. 통합 릴리스 증거는 `output/corp-release-20261029/`에 기록한다.
