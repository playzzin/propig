# PC 사무실 순차 검증 결과

확인일: 2026-09-16. VPS는 추후 진행한다.

이 문서는 앞선 순차 검증 당시의 기록이다. 당시 대기 중이던 Telegram 요청은 후속 검증에서 종료 이벤트와 최종 응답 124자의 일치를 확인했다. 최신 상태와 Python 106개 검사·100명 연결·10분 부하·백업 복원 결과는 [후속 검증 결과](hermes-office-phase4-results.md)를 참고한다.

## 이번에 완료한 항목

| 순서 | 결과 | 확인 근거 |
|---|---|---|
| 1. 사무실 복구 | 로그인 자동 시작 등록, 종료·응답 없음 복구 구현 | 실제 사무실 서버 종료 뒤 건강 상태 회복·8명 명부 보존. 복구 검사 5개 통과 |
| 2. Telegram 시작·진행 | 사용자 새 요청의 공식 시작·중간 이벤트 수신 | 해당 봇의 실제 메시지 메타데이터와 hook 실행을 대조. 최종 답변은 대기 중 |
| 3. AI 분담안 | 실제 직원이 작성한 2단계 계획을 검증·가져오기 | 모델 실행 1건, 업무 초안 생성 확인 |
| 4. 두 직원 협업 | GPT 결과를 Grok 직원이 받아 인계 확인 | 각각 1회 실행, 선행 결과 스냅샷 일치·실행 순서·인계번호 확인 |
| 5. 회의 | 두 의견을 받은 의장이 결론 작성 | 의견 2회·요약 1회, 요약에 두 의견 포함·실제 전달 결과 대조 |
| 6. 교육 실습 | 교육의 표식·보고 항목이 실제 응답에 반영 | 모델 실행 1회. 업무 요청과 완료 조건에는 표식을 직접 넣지 않음. 시험 교육은 철회 |
| 7. 확장·복구 시험 | 별도 시험 사무실 8→25→50→100명 | 184.31초·2,004개 합성 이벤트·100개 결과, 중간 강제 종료와 재시작, 중복 이벤트 억제, DB 무결성 통과 |

실제 AI 검사는 총 **7건**, 각각 **1회** 실행했다. 재시도 없이 결과를 검토하고 완료했다. API가 비용을 제공하지 않은 경우 금액을 임의로 계산하지 않는다. 검증용 결과·점수는 연결 흐름 검사용이며 일반 업무능력·교육 효과의 평가가 아니다.

## 사용자가 알아둘 변화

- PC 로그인 시 사무실 화면과 연결 확인기가 자동으로 시작한다.
- 서버가 종료되면 복구를 시도한다. 실제 종료 복구는 확인했으며 재부팅·재로그인 시험은 아직 하지 않았다.
- Telegram에서 추가 답변을 기다리는 봇은 **답변 대기**로 보이고 **대표 확인함**에 표시된다. 실제 처리 중인 것처럼 타이핑 연출을 계속하지 않는다.
- 협업 결과와 회의 결론은 업무 보드·프로젝트에서, 교육 적용·철회는 교육·지식에서 확인한다.
- 회사 기록 내보내기로 비개발자가 읽을 수 있는 보고서를 저장할 수 있다.

## 실행 범위와 검증

검증 실행기는 지정 업무만 실행하고 종료한다. 제출 전에 실행 기록을 저장하고 접수 여부가 불명확해도 자동 재전송하지 않는다. 서버에서도 대상 업무·기한·한 번 실행 조건을 검사한다. 끝나면 회사의 추가 실행을 일시정지한다. 로그인 자동 시작은 연결 확인 전용이며 업무 실행기를 자동으로 켜지 않는다.

자동 검사 **89개** 통과. 전체 TypeScript 검사, Office UI 검사, 화면 빌드, 실제 명부의 1440/390px 화면·8개 메뉴·접근성 자동 검사 통과. 별도 100명 브라우저에서 답변 대기→처리 재개→늦은 도구 반환, 협업 편집·교육·배치 변경도 확인했다. 실제 슈퍼피그의 답변 대기 캐릭터·대표 확인함도 화면에서 확인했다.

격리 HTTP 부하 시험의 쓰기 처리 시간은 p95 **32ms**, 조회는 p95 **31ms**였다. 이번 PC와 시험 데이터의 짧은 측정값이며 실제 AI 응답 시간이나 하루 이상 장시간 운영 성능을 뜻하지 않는다.

## 당시 남아 있던 실제 확인

1. Telegram에서 봇의 추가 질문에 답한 뒤 최종 응답→종료 이벤트→사무실 결과를 대조한다. **후속 검증에서 완료:** 23:32:03 한국시간에 종료 수신, 최종 응답 124자 일치. 사용자 업무의 내용상 승인은 하지 않고 검토 대기로 유지했다.
2. 실제 새 봇 계정이 추가되면 자동 명부 등록과 그 봇의 실제 실행 연결을 확인한다. 현재 실제 직원은 8명이다.
3. 실제 100개 계정과 장시간 모델 부하는 계정·API 한도·PC 자원에 맞춰 별도 확인한다. 이번 100명 검증에는 실제 모델 호출이 없다.
4. VPS와 외부 접속 환경은 사용자가 지정한 이후 단계에서 진행한다.
