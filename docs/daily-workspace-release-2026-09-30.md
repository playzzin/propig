# 2026-09-30 ProPig 통합 릴리스

사용자가 오늘 작업한 ProPig 변경 전체의 커밋·푸시·배포를 명시 요청했다. 통합 owner는 Hermes lead이며 Git·의존성·빌드·배포를 담당한다. shell/corp 역할은 읽기 전용 감사를 수행한다. 운영 사용자 데이터·권한·유료 생성과 기존 개발 서버는 보존한다.

## 범위

- 이미 배포된 스토리보드 프로젝트 삭제·제작 흐름 개선을 포함한 최신 코드.
- 기업 소개·대표 소개·이력서·사업 영상·제품 소개 개선과 폐기된 기업 프로젝트/포트폴리오 화면·메뉴 정리.
- 로그인·사이트 선택·프로필 메뉴·공통 레이아웃·사이트 모드 및 뒤로가기 일관성 개선.
- 이모티콘 스튜디오의 작업공간 폭에 맞춘 반응형 레이아웃과 공통 메뉴 통합 및 관련 회귀 검사.
- 현재 Git 변경 목록을 확정해 격리 snapshot에서 검증한다. 비밀 설정·개인 백업·임시 로그·테스트 산출물은 커밋 대상이 아니다.

## 검증 및 운영 적용

### 통합 중 보완

- 사용량·AI 설정 페이지에서 인증 상태가 바뀌어도 로그인 대화상자가 유지되도록 소유 위치를 페이지 최상위로 옮겼다. 선택한 사이트로 이동하기 전에 권한 확인을 기다리는 흐름이 중간에 해제되지 않는다.
- 실제 두 페이지의 대화상자 생명주기를 검사하는 `verify-login-entry-lifecycle.cjs`를 추가했다. 로딩·일반 회원·관리자·세션 교체 중 동일 대화상자가 유지되고 자체 닫기 이후 해제되는지 확인한다.
- 사용하지 않는 공통 헤더 변수·import를 제거했다.
- 기업 화면 검사는 연혁 시작/끝의 진행률 제한과 실제 중간 항목 스크롤을 함께 검증한다. 차트·영상의 모션 설정 반영은 브라우저 이벤트와 표시 완료를 기다린 후 판정한다.

### 실제 검증

- Windows 개발 서버와 의존성을 유지하고 Linux의 별도 소스 사본에 lockfile 기준으로 의존성을 설치했다. 최종 제품 코드의 정적 운영 빌드 52페이지, TypeScript, Functions 빌드, `npm test`, `verify:release-static` 통과.
- lint 오류 0개. 기존 경고 3개(window.location.assign, useMemo 의존성, 미사용 eslint-disable)는 남아 있다.
- 릴리스 브라우저 묶음 중 대시보드, 레지스트리 복구, 폰트, 이미지 예산, 업무함, 초대, 관리자 사용자, 북마크, 사이트 APK, 계정 도구, 공통 화면, 메모, 파비콘, 사이드바, 관리자 메뉴 검사 통과.
- 묶음 실행은 채용 초안 복원 대기에서 한 번 중단되었다. 동일 정식 채용 검사의 별도 재실행은 PC·모바일 모두 통과했고, 나머지 항목도 별도로 실행해 통과했다. 기업 화면 5개 × PC·모바일, 화면 이동, 제휴 문의, 이모티콘 자유 이동·편집·백업 복원까지 확인했다. 전체 묶음 명령을 한 번에 통과했다고 해석하지 않는다.
- 로그인·사이트 선택 Chromium 21개 시나리오, 로그인 진입 페이지 생명주기 2개, 폐기 메뉴 정리, 스토리보드 비로그인 PC·모바일 검사 통과.
- 사업 영상은 재생기 대역을 사용해 순환·키보드·지연 응답·빠른 선택·모션 감소·터치 드래그·좁은 화면을 검사했다. 사이트 선택 성능 검사도 통과했다.

### 검증 한계와 배포 범위

- 실제 유료 생성, 실제 사용자 프로젝트 삭제, 운영 인증·데이터 변경은 실행하지 않았다. 외부 YouTube 영상의 실제 재생은 이번 자동 검증에 포함하지 않았다.
- 이번 추가 변경은 Hosting 대상이다. 이미 배포된 스토리보드 서버 기능, Functions 설정, Firestore·Storage 규칙에는 추가 변경이 없다.
- 운영 배포 및 파일 대조 결과는 배포 완료 후 기록한다. 이전 스토리보드 배포 기록은 `docs/storyboard-intent-completion-handoff.md`에 있다.
